# Python Rock, Paper, Scissors

A classic Rock, Paper, Scissors game implemented in Python. Features a playable command-line interface, randomized computer logic, and continuous round tracking.

---

## Features

- **Command-Line Interface:** Play the game directly from your terminal.
- **Continuous Gameplay:** Keep playing rounds until you decide to exit.
- **Randomized Logic:** Built-in Python `random` library cleanly handles the computer's selections.

---

## Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ZynzTehr/python-rock-paper-scissors.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd python-rock-paper-scissors
   ```

3. **Run the game:**
   Ensure you have Python 3 installed, then execute:
   ```bash
   python3 rps/rps.py
   ```

4. **Play:** Enter `rock`, `paper`, or `scissors` when prompted. Type `quit` or `exit` to end the session.
